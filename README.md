This Bazar Dor website has been built using the following modern technologies:

Next.js (App Router): Used for website routing and performance optimization.

React.js: Used as the core library for building the user interface (UI).

Tailwind CSS: Used for creating beautiful designs and responsive layouts.

Better Auth: Used for secure user authentication and sign-in/sign-up management.

React Toastify: Used for displaying success or error messages in pop-ups.

React Icons: Used for displaying various icons.

TypeScript: Used to keep the code more type-safe and secure.
